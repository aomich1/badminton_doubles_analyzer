# バドミントン ダブルス動画分析

Mac / Windows 対応のローカル動作アプリです。実行すると既定のブラウザーで分析画面を開きます。アプリは `127.0.0.1` だけで待ち受け、動画や分析結果を外部へ送信しません。

## 機能

- スマホ動画の再生とシーク（対応コーデックは既定ブラウザーに依存）
- コート図でダブルス4選手の位置を手動記録
- `.bdx` プロジェクトの保存・読み込み（JSON形式）
- BWFのコート寸法とライン配置に合わせた横向きコート図
- 解析前の段階式設定（コート確認・確定 → 選手確認・確定）
- コート線色と選手ごとの服色・靴色の複数サンプルを `.bdx` プロジェクトに保存
- MediaPipe Pose Landmarker Fullによる映像全体の人物候補検出（最大12人）と4人への手動割り当て、コート角と選手位置の手動補正
- 再生・シーク中のコート線と選手位置の定期的な再検出・追従

姿勢検出には精度優先のFullモデルを使用します。Liteより処理負荷が高くなります。候補検出ではコート枠による除外をせず、映像全体から最大12人を検出します。検出候補一覧から選び、割り当て先のプレイヤーを指定して「選手に割当」を押します。初期検出は動画を開いた時点の1フレームで行い、選手確定後は再生・シーク時のフレームを定期的に再解析してコート線と選手位置を補正します。ライン色はコート内の明るい/黄色い画素の平均、選手の服色と足首・かかと・つま先付近の靴色は色サンプルとして個別に複数保存し、選手の再対応付けに使います。初期設定で選手を選び「服・靴の色を学習」を押すと、そのフレームの色が追加されます。照明や姿勢が異なる場面でも繰り返し学習すると、保存した複数の色サンプルから照合します。既存の色サンプルと一致する候補は自動照合し、それ以外は候補一覧から手動で割り当てます。選手番号はコートの自分側・相手側とは結び付けません。追跡は姿勢候補・前回位置・服色と靴色の近さに基づく簡易方式で、学習済み色の一致を位置より優先するためコートチェンジ後も同じ選手名を保ちやすくしています。人物の重なり、遠距離、暗さ、カメラ角度、照明変化、同色の服や靴などで検出漏れや誤対応が起こるため、初期設定で結果を確認・修正してください。シャトル検出とショットの自動評価は未実装です。

コート図はBWF Laws of Badminton, Section 4.1, Diagram Aに基づき、全長13.40 m、ダブルス幅6.10 m、シングルス幅5.18 m、ネットからショートサービスラインまで1.98 m、後方境界からダブルスロングサービスラインまで0.76 m、ライン幅40 mmを実寸比で描画します。

## Macでのビルド・起動

1. `build_macos.command` をダブルクリックします。
2. 初回はインターネット接続が必要です（PyInstallerの取得）。
3. ビルドが終わると `dist/BadmintonDoublesAnalyzer.app` が作成されます。
4. Finder でアプリを開いてください。ビルド用ターミナルから実行ファイルを直接起動しても、新しいターミナルは開きません。

ビルド結果は `build_macos.log` に保存します。失敗した場合はスクリプトがログ末尾を表示して停止します。Python 3 と pip が必要です。

## Windowsでのビルド・起動

1. Windows PC で `build_windows.bat` をダブルクリックします。
2. ビルド後、`dist\BadmintonDoublesAnalyzer.exe` ができます。
3. `.exe` を起動すると既定のブラウザーで画面を開きます。

ビルドにはインターネット接続が必要です。Windows 用 `.exe` は Windows 上でビルドしてください。

## 操作

1. 「動画を開く」で試合動画を選択します。
2. 初期設定で映像上のコート外枠4点を確認・修正し、「コートを確定して選手へ」を押します。内側のラインはBWF実寸比に固定され、外枠の透視変形に合わせて表示されます。次に選手候補を確認して「4人確定」を押します。選手を1人ずつ選び、姿勢や照明の異なる場面で「服・靴の色を学習」を繰り返すと、その選手の色サンプルが追加されます。登録状況は各選手名の横に表示されます。「選手を検出・照合」を押すと、保存した複数の服色・靴色サンプルと照合してコート図に同じ選手名で表示します。再生・シーク中は位置を定期的に更新します。
3. 動画を一時停止し、記録対象の選手を選んでコート図上の位置をクリックします。
4. 「プロジェクトを保存」で `.bdx` ファイルを保存します。

プロジェクトを読み込んだ後、元の動画も改めて選択してください。動画自体はプロジェクトに含めません。
旧版の縦向きコートで保存したJSONプロジェクトは、位置座標を横向きに変換して読み込みます。

## 動画について

`.mp4` や `.mov` の再生可否はコンテナだけでなく動画コーデックとブラウザーに依存します。再生できない場合は、H.264 の MP4 に変換してお試しください。
